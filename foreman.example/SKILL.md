# foreman
What goes here: how to route `$ARGUMENTS` to a mode, which files to always load, and where tasks live.
Example: Load `me/*.md` and `context.md` first. A link → `modes/triage.md`; `go 1 3` → `modes/go.md`; anything else → `modes/<first word>.md`.
